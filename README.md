# design-kit

Working collection of design and presentation material: brand systems, slide
tooling, UX artefacts and the reusable assets behind them.

## Layout

| Folder | Contents |
|---|---|
| `branding/` | Palettes, type scales, logo usage, brand system notes |
| `pptx/` | PowerPoint tooling and templates |
| `ux/` | Wireframes, flows, interaction patterns, research notes |
| `assets/` | Shared source files: icons, images, fonts metadata |

Each tool lives in its own folder with a README describing what it does and how
to run it.

## Tools

- [`pptx/theme-swap`](pptx/theme-swap) — convert a `.pptx` between two colour
  and font themes, reversibly.

## Conventions

- One folder per tool or artefact, with its own README.
- No client names, credentials or licensed font files in this repository.
- Scripts use the standard library only unless a dependency is documented.
